문장 배틀 샘플 v9

[핵심 변경]
1. 교사용 경기 화면을 전광판형으로 단순화
   - 진행 중에는 문장/카드를 보여주지 않음
   - 큰 타이머, 제출 인원, 실시간 순위만 표시
   - 제한시간 종료 또는 전원 제출 후 대표 정답 문장을 5초간 표시
2. 실제 학생 휴대폰 화면 추가: play.html
   - PIN/QR 입장
   - 닉네임/캐릭터 선택
   - 카드가 위에서 날아와 제시
   - 학생 각자 휴대폰에서 문장 조립 및 제출
   - 정답 제출 순위에 따라 차등 점수
3. 10명 데모 시연
   - 가상 학생 10명이 자동 참여
   - 제출/점수/순위/정답 공개 흐름 자동 시연
4. 기존 기능 유지
   - 문제당 풀이 시간 설정
   - 출제 문장 선택/제외
   - 문장 수정
   - 새 문장 추가
   - 복수 정답 어순
   - 동사·형용사 종결형은 한 카드
   - 교사용 전체화면/음량/홈

[설치 위치]
C:\korean-word-battle-firebase-v7.4\sentence-battle-sample

이 샘플은 상위 프로젝트의 js/firebase-config.js를 사용합니다.
실제 학생 입장은 기존 어휘 게임과 같은 Firebase 프로젝트의 rooms 경로를 사용합니다.

[PC 로컬 테스트]
cd C:\korean-word-battle-firebase-v7.4
python -m http.server 8000

교사용:
http://localhost:8000/sentence-battle-sample/

학생 화면 직접 열기:
http://localhost:8000/sentence-battle-sample/play.html

실제 휴대폰은 localhost로 PC에 접속할 수 없습니다. 같은 Wi-Fi에서 PC의 IPv4 주소로 접속하거나, GitHub Pages 배포 주소에서 테스트하세요. Firebase Authorized Domains 설정에 따라 IP/도메인 추가가 필요할 수 있습니다.


[업데이트 v10]
- 교사용 경기 화면에서 큰 타이머와 함께 현재 문제의 제시 카드 목록을 표시합니다.
- 제시 카드 순서는 학생 휴대폰에 전달되는 동일한 셔플 순서를 사용합니다.
- 교사용 화면에서는 카드 조립 결과를 보여주지 않으며, 제한 시간 종료/전원 제출 후 대표 정답을 5초간 공개하는 흐름은 그대로 유지합니다.


[v11 추가]
- 교사용 모니터: 학생 한 명이 정답을 제출할 때마다 전체 화면 축하 폭죽
- 정답 학생 이름/점수 짧게 표시
- 문제 풀이 중 긴장감 있는 반복 음을 계속 재생하며 남은 5초에는 더 빨라짐
- 기존 음량 슬라이더/음소거가 긴장음과 폭죽 효과음에도 적용됨


[v12 / v2.2]
- 교사용 경기 화면의 긴장 배경음을 훨씬 크게 조정: 저음 지속 베드 + 반복 리듬 + 마지막 5초 가속
- 음량 슬라이더/음소거 변경 즉시 배경음에 반영
- 정답 공개 문장은 먼저 한 줄에 맞춰 자동 축소
- 한 줄이 불가능한 긴 문장만 어절(띄어쓰기) 단위로 최대 두 줄 표시


[v13 화면 개편]
- 교사용 진행 화면 순서: ROUND -> 제시 카드 -> 원형 카운트다운 -> 제출 인원
- 기존 직선 타이머 제거, 굵은 원의 색이 줄어드는 원형 타이머 적용
- 남은 시간이 줄면 원 색상이 청록 -> 노랑 -> 빨강으로 변화
- 정답 공개 화면은 가장 위에 큰 '정답' 표시, 그 아래 정답 문장을 한 줄로 화면 폭에 자동 맞춤
- 정답 공개 시간은 기존 5초 설정 유지

[v14 업데이트]
- 교사용 진행 화면의 원형 타이머를 더 크게 확대했습니다.
- 제시 카드와 제출 표시 사이의 남는 공간을 타이머 전용 영역으로 만들고, 원형 타이머를 그 공간의 정확한 중앙에 배치했습니다.
- 전체 문항 중 마지막 30%에 들어가면 실시간 순위 목록을 숨기고 '순위 비공개' 상태로 전환합니다.
- 최종 결과 화면에서는 순위를 다시 공개합니다.


[v15] 정답 공개 화면 디자인 개선
- 기존 밝은 크림색 정답 박스를 제거하고 게임 전체 톤과 맞는 고급형 다크 글래스 패널로 변경
- 정답 라벨은 상단에 크게 유지하고 청록/골드 포인트 라인 추가
- 정답 문장은 흰색 대형 글씨와 은은한 그라데이션 테두리로 한 줄 표시 유지
- 복수 정답 안내와 다음 문제 카운트다운도 간결한 반투명 배지 스타일로 정리
- 게임 진행 화면, 타이머, 순위, 30% 블라인드 등 다른 기능은 변경하지 않음


[v16 PC 학생 모바일 미리보기]
- 교사용 대기실의 "학생 모바일 화면 테스트" 버튼은 play.html?preview=1을 엽니다.
- PC에서는 390x844 비율의 휴대폰 뷰포트로 학생 화면을 테스트합니다.
- QR로 실제 휴대폰이 접속할 때는 기존처럼 휴대폰 전체 화면을 사용합니다.
- 미리보기와 실제 휴대폰은 같은 학생 UI/JS를 사용하므로 화면과 동작 차이를 줄였습니다.


[v20 유연 어순 판정]
- 대표 정답 문자열 1개와 정확히 같아야 하는 방식에서 확장
- 조사와 결합된 문장 성분(주제/주어/목적어/장소/시간 등)을 덩어리로 유지하면서, 서술어 앞에서 자연스럽게 이동 가능한 성분은 여러 순서로 배치해도 정답 처리
- 예: 저는 오늘 학교에 갑니다 / 오늘 저는 학교에 갑니다 / 학교에 오늘 저는 갑니다 등 문법적으로 성립하는 등록 프레임의 어순을 자동 인정
- 조사 자체가 잘못 붙거나 서술어 위치가 깨지는 임의 순열은 정답 처리하지 않음
- 교사가 직접 추가/수정한 문장도 입력한 정답을 기준으로 유연 어순 프레임을 자동 생성
