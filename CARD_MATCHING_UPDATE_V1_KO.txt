한·몽 카드 매칭 게임 추가 업데이트 V1
=====================================

1. 이번 업데이트 핵심
- 메인 '한국어 게임 아레나'의 기존 비활성 '스피드 러시' 자리를 '카드 매칭' 게임으로 교체했습니다.
- 학생은 교사가 만든 방의 QR/PIN으로 휴대폰에서 입장합니다.
- 한국어 카드와 몽골어 카드를 같은 뜻끼리 선택하면 해당 카드 두 장이 사라집니다.
- 빠르게 맞출수록 높은 점수를 받고, 연속 정답(COMBO) 보너스와 빠른 판 완료 보너스가 적용됩니다.
- 전체 게임 진행률 70%를 넘으면(마지막 30%) 학생 점수와 교사용 순위가 자동으로 가려집니다.
- 게임 종료 후 최종 점수/순위를 다시 공개합니다.

2. 교사용 설정
- 자료: 예비편 어휘 40 / 서울대 한국어 / TOPIK 1 연어 표현
- 어휘 직접 선택 가능
- 판 수: 1 / 3 / 5 / 7 / 10판
- 한 판 카드: 4~8쌍(8~16장), 기본 6쌍
- 제한 시간 빠른 버튼: 20 / 30 / 45 / 60 / 90초
- 직접 조절: 15~120초
- BGM / 효과음 / 음량 조절
- 마지막 30% 자동 블라인드 고정 적용

3. 게임 화면
- 교사용 화면: 상단에 이번 판의 한국어/몽골어 카드가 무작위로 표시되고, 중앙에는 원형 컬러 타이머가 표시됩니다.
- 학생 화면: 원형 타이머 + 실제 카드 느낌의 한국어/몽골어 카드 보드가 표시됩니다.
- 맞춘 카드는 애니메이션 후 학생 화면에서 제거됩니다.
- 틀린 조합은 흔들림 효과 후 다시 선택할 수 있습니다.
- 학생 점수 상승 시 +점수 애니메이션이 표시됩니다.

4. 수업용 기능
- 10명 데모 시연: 가상 학생이 자동으로 매칭하며 순위 변화와 블라인드 구간까지 시연합니다.
- 혼자 게임: 교사가 학생 화면을 직접 테스트할 수 있습니다.
- 실제 게임: Firebase 연결 시 여러 학생이 서로 다른 휴대폰에서 동시에 경쟁합니다.
- QR/PIN 입장 구조는 기존 실시간 어휘 배틀 방식과 호환됩니다.

5. 데이터 안정성
- 한 판 안에서 한국어/몽골어 표현이 중복되어 정답이 모호해지지 않도록 1:1 매칭 가능한 항목만 구성합니다.
- 선택한 어휘를 가능한 한 골고루 사용한 뒤 다음 판에서 재사용합니다.

7. Firebase Database Rules
- 기존 inbox/state 구조를 그대로 사용하므로 firebase-database-rules.json 변경은 필요하지 않습니다.

8. PC 로컬 테스트 예시
프로젝트 폴더에서 PowerShell을 열고:
python -m http.server 8000

브라우저:
http://localhost:8000/

메인 화면에서 '카드 매칭' 선택 -> 자료 선택 -> 게임 설정 열기
- [혼자 게임]으로 학생 화면 테스트
- [데모 시연] -> [게임 시작]으로 10명 자동 시연 테스트

주의: 실제 학생 휴대폰 QR/PIN 입장은 Firebase 설정이 완료된 GitHub Pages/웹 서버 주소에서 테스트하세요.
